# JapanizeStarValor
Star Valor(https://store.steampowered.com/app/833360/Star_Valor/)の日本語化プロジェクト

## 概要
このプロジェクトは、ゲーム「Star Valor」のテキストを日本語に翻訳するためのGUIツールを提供します。

## 機能
- ゲームテキストファイルの読み込み
- SQLiteデータベースへの格納
- 翻訳作業用のGUIインターフェース
- 翻訳済みテキストのエクスポート

## 使い方

### 必要な環境
- Python 3.6以上
- tkinter（標準ライブラリ）

### アプリケーションの起動
```bash
python translation_gui.py
```

### 翻訳作業の流れ
1. **読み込み**: メニューまたはボタンから「読み込み」を選択し、ゲームテキストファイルを読み込みます
2. **翻訳**: 各エントリの原文を見ながら、翻訳欄に日本語訳を入力します
3. **ナビゲーション**: 「次」「前」ボタンまたは一覧から次のエントリに移動します
4. **エクスポート**: 翻訳が完了したら「エクスポート」でテキストファイルを保存します

### テキストファイルのフォーマット
```
#=============|
[0] Basic/Fixed UI    |
#=============|
000 Loading|
001 New Game|
...
```

## ファイル構成
- `translation_gui.py` - メインGUIアプリケーション
- `text_parser.py` - テキストファイルのパーサー
- `database.py` - SQLiteデータベース管理
- `sample_text.txt` - サンプルテキストファイル
