# JapanizeStarValor / Star Valor 日本語化プロジェクト

## 概要

[Star Valor](https://store.steampowered.com/app/833360/Star_Valor/)を日本語化するプロジェクトです

## リポジトリ構成

### JapanizeStarValor/translated

翻訳用のパッチファイルが置かれています。[Flips](https://github.com/Alcaro/Flips)とかを使えばパッチを当てられます。

リリースにまとめるのは適当に一段落ついたタイミングなので、最新の状況が反映されているのはこちらです。

アップデート直後とかはこっちのほうが新しいかもしれません。

### JapanizeStarValor/translation_supporter

翻訳支援用のアプリが入っています。詳しくはディレクトリ内のREADMEを読んでください。
