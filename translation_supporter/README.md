# JapanizeStarValor / Star Valor 日本語化プロジェクト / ローカライズ支援プログラム

## 概要
ゲーム "Star Valor" のテキストを日本語に翻訳するためのGUIツールです

## 機能
- ゲームテキストファイルの読み込み
- SQLiteデータベースへの格納
- 翻訳作業用のGUIインターフェース
- 翻訳済みテキストのエクスポート
- 過去の翻訳ファイルからの翻訳インポート
- 原文・翻訳語句の検索機能

## 使い方

### 必要な環境
- Python 3.6以上
- tkinter（標準ライブラリ）

### アプリケーションの起動
```bash
python translation_gui.py
```

### 翻訳作業の流れ
1. **読み込み**: メニューまたはボタンから「読み込み」を選択し、ゲームテキストファイルを読み込みます
2. **過去の翻訳をインポート（任意）**: メニューから「ファイル」→「過去の翻訳をインポート」を選択し、以前に翻訳したファイルを読み込むことで、一致するエントリの翻訳を引き継ぐことができます
3. **翻訳**: 各エントリの原文を見ながら、翻訳欄に日本語訳を入力します
4. **検索**: メニューから「編集」→「検索」を選択し、原文や翻訳語句を検索できます。これにより、特定の単語の翻訳が一貫しているか確認できます
5. **ナビゲーション**: 「次」「前」ボタンまたは一覧から次のエントリに移動します
6. **エクスポート**: 翻訳が完了したら「エクスポート」でテキストファイルを保存します

### ゲームのバージョンが上がった場合
ゲームのバージョンが上がった場合、再度ゲームのテキストファイルを読み込み、DBを再構成する必要があります。

**必ず現在の翻訳状況をエキスポートしてから**、生成される`translations.db`を削除してください。

翻訳状況は、インポート機能から引き継ぐことが出来ます。

### 過去の翻訳をインポート
過去に翻訳したファイルがある場合、その翻訳を新しいバージョンのファイルに引き継ぐことができます。

1. まず新しいバージョンのゲームテキストファイルを「読み込み」で読み込みます
2. メニューから「ファイル」→「過去の翻訳をインポート」を選択
3. 過去に翻訳して**エクスポートした**ファイルを選択
4. IDが一致するエントリの翻訳が自動的にインポートされます

### 検索機能
特定の単語の翻訳を確認したい場合、検索機能が利用できます

1. メニューから「編集」→「検索」を選択
2. 検索語を入力し、「原文」または「翻訳」を選択
3. 「検索」ボタンをクリック
4. 検索結果が一覧表示されます
5. 結果をダブルクリックすると、そのエントリにジャンプします

## ファイル構成
- `translation_gui.py` - メインGUIアプリケーション
- `text_parser.py` - テキストファイルのパーサー
- `database.py` - SQLiteデータベース管理
- `sample_text.txt` - サンプルテキストファイル
