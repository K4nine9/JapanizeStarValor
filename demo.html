🎮 Star Valor Translation Tool

Star Valorゲームのテキストを日本語に翻訳するためのGUIツールです。

📋 機能

✓ テキストファイルのパース
ゲームの特殊なフォーマット（セクションヘッダー、番号付きエントリ）を解析
✓ 複数行エントリのサポート
改行を含むテキストや空行にも対応
✓ SQLiteデータベース
翻訳データを永続化し、作業の中断・再開が可能
✓ 直感的なGUI
tkinterベースのシンプルで使いやすいインターフェース
✓ エクスポート機能
翻訳済みテキストを元のフォーマットで出力

🚀 使い方

  1. アプリケーションの起動
    python translation_gui.py
  2. テキストファイルの読み込み
    「読み込み」ボタンをクリックしてゲームテキストファイルを選択
  3. 翻訳作業
    原文を確認しながら翻訳欄に日本語訳を入力（自動保存）
  4. ナビゲーション
    「次」「前」ボタンまたは一覧から次のエントリに移動
  5. エクスポート
    「エクスポート」ボタンで翻訳済みテキストを保存

💾 技術仕様

  • 言語: Python 3.6+
  • GUI: tkinter (標準ライブラリ)
  • データベース: SQLite3
  • 対応形式:
    • 標準的な1行エントリ
    • 空行エントリ（番号と | のみ）
    • 複数行にまたがるエントリ

📂 ファイル構成

  • translation_gui.py - メインGUIアプリケーション
  • text_parser.py - テキストファイルのパーサー
  • database.py - SQLiteデータベース管理
  • sample_text.txt - サンプルテキストファイル
✓ プロジェクト完成
